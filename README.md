# ECG Trainer-Team · Schnupperkurs 2026

Interne Seite mit allen Teilnehmerlisten (Schuhe & Bezahlt, Anwesenheit, nach Vorname, Gruppen, Gesamtliste).


## Datenschutz

Die Kinderdaten stehen **nicht lesbar** im Quelltext, sondern sind mit dem Passwort
verschlüsselt (AES-256). Erst nach Eingabe des richtigen Passworts werden sie im Browser entschlüsselt.

Wichtig: Ein 4-stelliges Passwort hält normale Besucher fern, ist aber für jemanden mit
technischem Wissen knackbar (nur 10.000 Möglichkeiten). Die Seite also nur im Trainer-Team
teilen, den Link nicht öffentlich posten und nach der Saison wieder löschen.
